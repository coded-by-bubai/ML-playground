# 🧠 ML Playground

**A hands-on collection of Machine Learning algorithms implemented using Python and Jupyter Notebook.**

Welcome to **ML Playground**, a repository dedicated to learning, implementing, and experimenting with fundamental Machine Learning algorithms. This project provides a practical approach to understanding how different algorithms work, how models are trained, and how they can be applied to real-world datasets.

## 🚀 About the Project

ML Playground is a practical learning repository for exploring core Machine Learning algorithms through Python notebooks.

Each notebook focuses on a particular algorithm, providing an environment to experiment with data, understand model behavior, and build a stronger foundation in Machine Learning.

Whether you're a beginner starting your ML journey or a student preparing for projects and technical interviews, this repository can serve as a useful reference.

### 🔍 What You'll Explore

- **KNN:** Understand distance-based learning and classification.
- **Linear Regression:** Learn how to model relationships between variables and predict continuous values.
- **Logistic Regression:** Explore classification using probability-based predictions.
- **SVM:** Understand decision boundaries, maximum-margin classification, and support vectors.

## 🛠️ Tech Stack

- **Language:** Python
- **Environment:** Jupyter Notebook
- **Libraries:** NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn, depending on the notebook requirements.

## ⚙️ Getting Started

### Prerequisites

Make sure you have Python 3 installed on your system.

### 1. Clone the repository

```bash
git clone https://github.com/coded-by-bubai/ML-playground.git
```

### 2. Navigate to the project directory

```bash
cd ML-playground
```

### 3. Create a virtual environment (recommended)

```bash
python -m venv .venv
```

Activate the environment:

**Windows**
```bash
.venv\Scripts\activate
```

**Linux / macOS**
```bash
source .venv/bin/activate
```

### 4. Install the required libraries

```bash
python -m pip install jupyter numpy pandas matplotlib seaborn scikit-learn
```

### 5. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open any notebook in the browser and run the cells sequentially.
